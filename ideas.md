# Summa AI — Design Direction

## Redesign: Aetheris Glassmorphism

The design direction has been updated to pixel-perfectly match the Aetheris reference provided by the user. The previous "Margin Classroom" direction is replaced by a modern, airy, glassmorphism-inspired visual system.

### Design Movement

**Aetheris Glassmorphism** combines soft pastel gradients, translucent blurred surfaces, and generous rounded geometry. It feels futuristic, calm, and highly polished. The interface is an inset glass shell that floats over a vibrant but soft background.

### Core Principles

1. **Translucency and Depth.** Use backdrop-blur, subtle white borders, and diffuse shadows to create a layered glass effect.
2. **Soft Vibrant Palette.** A full-viewport gradient of cyan, lavender, and pale green provides the emotional backdrop.
3. **Generous Whitespace.** Content is given ample room to breathe, emphasizing clarity and focus.
4. **Rounded Geometry.** Large corner radii (24px+) define the application shell, cards, and interactive elements.

### Color Philosophy

The background is a soft, multi-color pastel gradient. The application shell is a semi-transparent white (`rgba(255, 255, 255, 0.6)`) with a strong backdrop-blur. Accents use vibrant but soft gradients, particularly a blue-to-purple gradient for primary actions and user messages.

### Layout Paradigm

An inset application shell with two main zones:
- **Sidebar:** Narrow, pale glass, containing utility navigation, course folders, and the user profile.
- **Main Canvas:** Spacious, containing the chat interface or secondary learning surfaces.

### Signature Elements

1. **The Glass Shell:** A large rounded container that holds the entire application.
2. **The Orb Avatar:** A 3D-like iridescent orb represents the AI identity.
3. **The Rounded Composer:** An oversized, highly rounded input area with integrated tool selectors.
4. **Gradient Bubbles:** User messages are encased in soft blue-purple gradient bubbles.

### Interaction Philosophy

Interactions are fluid and tactile. Buttons use subtle scale transforms on active states. Glass surfaces use low-contrast hover states. The transition between chat and learning activities is seamless within the same canvas.

### Animation

Snappy but soft transitions. Views fade and slide slightly. The composer and cards use 200-300ms ease-out transitions for state changes.

### Typography System

**Manrope** remains the primary typeface for its modern, readable, and friendly tone. Hierarchy is established through weight and size rather than high-contrast font pairings.

### Brand Essence

**Summa AI is the modern, intelligent learning companion that makes university education feel clear, personalized, and effortless.**

Personality: **futuristic, calm, sophisticated.**

### Wordmark & Logo

The wordmark is clean and typographic, following the Aetheris style. The logo is a soft, iridescent orb that suggests multi-dimensional intelligence and synthesis.

### Signature Brand Color

**Aetheris Gradient (Blue to Purple).**
