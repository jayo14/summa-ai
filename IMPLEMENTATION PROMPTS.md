# Summa AI — Implementation Prompts & Specification Roadmap (`IMPLEMENTATION PROMPTS.md`)

This document provides dependency-ordered, specific implementation instructions for bringing the Summa AI codebase to full target capability as an adaptive, reasoning-driven learning intelligence system.

---

## 🗺️ Dependency-Ordered Implementation Plan

### Prompt 1: Core Pedagogical Orchestrator Directive Injection & Execution
**Goal:** Wire `LearningOrchestrator` decision output directly into `build_orchestrator_prompt()` so that the AI's generated response strictly executes the chosen pedagogical action (`TEACH`, `EXPLAIN`, `EXAMPLE`, `RECALL`, `FLASHCARD`, `QUIZ`, `PRACTICE`, `ASSESS`, `REVIEW`, `COMPARE`, `APPLY`, `REFLECT`, `SIMULATE`, `PREDICT`, `PLAN`, `REST`).

**Files:** `api/app/routes/chat.py`, `api/app/services/orchestrator.py`

**Instructions:**
1. Update `build_orchestrator_prompt()` in `routes/chat.py` to accept `decision: Optional[OrchestratorDecision]`.
2. When `decision` is present, append explicit prompt instructions forcing the model to adopt the corresponding teaching posture (e.g. for `RECALL`: "Conduct a quick, active recall check before giving the answer"; for `COMPARE`: "Contrast the concept with potential misconceptions"; for `SIMULATE`: "Walk through a step-by-step scenario").
3. Ensure natural conversational cues (e.g. "I'm lost", "Quiz me", "Explain simply", "I keep forgetting") mapped by `detect_intent()` or orchestrator logic produce tailored pedagogical context.

---

### Prompt 2: Complete Interaction & Retention Write-Loop Integration
**Goal:** Connect interactive activity submissions (`/interactions/quiz-result`, `/interactions/flashcard-review`, `/interactions/practice-result`) to the multi-engine intelligence loop.

**Files:** `api/app/routes/interactions.py`, `api/app/services/mastery_engine.py`, `api/app/services/misconception_engine.py`, `api/app/services/spaced_repetition.py`

**Instructions:**
1. In `interactions.py`, when a student submits an answer:
   - Call `MasteryEngine.record_attempt()` to update 6D mastery scores.
   - Call `MisconceptionEngine.record_interaction()` to detect and record active misconceptions if the attempt failed or exhibited confusion.
   - Call `SpacedRepetitionEngine.record_review()` to update SM-2 review intervals and calculate forgetting risk.
   - Save the event in `DataStore` and log progress in `CogneeService`.
2. Return updated mastery estimates and next review recommendations in the response payload.

---

### Prompt 3: Spaced Repetition & Knowledge Decay Recall in Chat Context
**Goal:** Automatically surface concepts due for spaced review or at risk of forgetting into the chat turn decision process.

**Files:** `api/app/routes/chat.py`, `api/app/services/spaced_repetition.py`

**Instructions:**
1. In `chat_stream()`, query `SpacedRepetitionEngine.get_due_reviews(user_id)`.
2. If review items are due and the user is starting or transitioning a session, inject a gentle proactive review suggestion or incorporate the weak/decaying concept into the orchestrator prompt.
3. Ensure the student is never forced into review, but the tutor is aware of forgetting risk.

---

### Prompt 4: Dynamic Component SSE & Artifact Synchronization
**Goal:** Ensure dynamic component artifacts generated by `generate_component_payload()` stream cleanly via SSE to the frontend `ChatComponentRenderer`.

**Files:** `api/app/routes/chat.py`, `client/src/pages/Home.tsx`, `client/src/components/chat/ChatComponentRenderer.tsx`

**Instructions:**
1. Verify `chat_stream()` emits `artifact` events formatted with valid JSON payloads matching the frontend `ActivityData` interface.
2. In `Home.tsx`, process incoming `artifact` events, attach them to message objects, and render them using `<ChatComponentRenderer activity={message.activity} />`.
3. Wire component completion callbacks in the UI to post results back to `/api/v1/interactions/*` endpoints.

---

### Prompt 5: End-to-End Verification & Real User Learning Journey Test
**Goal:** Verify the full end-to-end learning loop in real conversations:
`Understand → Diagnose → Decide → Teach → Interact → Assess → Update Learner Model → Adapt → Remember → Review → Predict → Prepare`

**Instructions:**
1. Execute pytest suite covering authorization, orchestrator decisions, mastery engine, misconception engine, spaced repetition, and interaction recording.
2. Verify clean execution with zero test failures or unhandled exceptions.
