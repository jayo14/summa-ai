# Summa AI — Aetheris Reference Ground Truth

The attached Aetheris screenshots are the visual ground truth for this redesign. The implementation must follow the reference composition and visual language closely while preserving Summa AI’s learning-specific content and interactions.

## Visual contract

The reference uses a soft full-viewport pastel gradient backdrop with cyan, lavender, blue, and pale green fields. A large translucent glass application shell is inset from the viewport with generous rounded corners, subtle white borders, diffuse shadows, and a lightly blurred surface.

The shell is divided into a narrow left utility sidebar and a spacious main content canvas. The sidebar includes a compact brand mark/wordmark, a prominent white rounded New chat button, vertically spaced utility navigation, folder sections with nested chat items, and a bottom profile card. The main canvas uses a restrained top bar, a centered AI identity mark, large greeting or conversation content, rounded translucent cards, and an oversized rounded composer anchored near the bottom.

## Interaction contract

The composer uses a large rounded input surface with a small placeholder, attachment/plus control, microphone control, data-source selector, and a circular gradient send button. Suggested actions appear as lightweight text/icon chips above or below the composer. Conversation messages use generous spacing, small AI avatar marks, rounded gradient student bubbles, and inline content cards. Dashboard-like information appears inside the conversation as compact stat cards rather than as a separate dense dashboard.

## Summa adaptation

Replace Aetheris brand text and generic tool categories with Summa AI learning equivalents: Workspace, My learning, Progress, Sources, recent learning conversations, course folders, study objects, learning context, source selector, interactive quiz, guided practice, flashcards, mastery evidence, and adaptive next action. Keep the Aetheris visual hierarchy, proportions, glass surfaces, pastel palette, rounded geometry, whitespace, and chat-first composition. Do not retain the previous dark editorial shell as the primary aesthetic.

## Pixel-fidelity priorities

1. Full-viewport pastel gradient background.
2. Inset translucent rounded shell with two-zone layout.
3. Narrow pale-glass sidebar with white New learning CTA and bottom profile card.
4. Spacious airy main canvas with top-center workspace label.
5. Rounded, low-contrast glass content cards.
6. Oversized bottom composer with circular purple-blue send control.
7. Soft gradients, blur, subtle borders, restrained shadows, and high whitespace.
8. Responsive mobile collapse while preserving the same pastel glass language.
