# Summa AI — Reference Pattern Findings

The reference list is retained verbatim in `docs/REFERENCE_LIST_SOURCE.md`. The visual references are input to pattern study only; none are copied.

## Reviewed Patterns

The Dribbble student AI chat reference uses a strong dark conversation shell, clear prompt-focused input, and card-like learning moments. Its three-phone presentation reinforced that the product should feel equally composed across entry, chat, and assessment states. The supplied analysis of Chat FZ, Kata Studio, and comparable AI SaaS shells identifies dense-but-legible conversation history, source-aware composition, and responsive collapsible navigation as relevant structural patterns. Adaptive-learning references point to compact mastery signals and recommendation moments, but their dashboard-first organization is intentionally not adopted.

## Synthesized Direction

Summa AI will borrow **hierarchical focus**, **deliberate white space around conversational turns**, **clear conversation history**, **a tactile composer**, **inline activity framing**, and **contextual progress visibility**. It will reject generic gradient-heavy AI aesthetics, course-card grids, achievement gamification, and a permanent analytics dashboard.

The result is a calm, editorial learning desk: a mature academic workspace that uses an ink-like navigation gutter, a paper-toned thinking surface, an adaptive study rail, and highly legible learning artifacts. The interface acts like a margin around the learner's reasoning rather than competing for attention.
